## 📌 Project Overview
This repository contains the computational pipeline, datasets, and empirical results for the research project investigating how **AI Agency** moderates the relationship between the **Artificial Linguistic Veneer (ALV)** and **Oral Accountability (ODP)** in postgraduate academic writing.

**Core Research Question:** Does the presence of perceived AI Agency diminish the negative impact of linguistic veneers on academic accountability?

---

## 📂 Repository Structure

The repository is organized into four layers to ensure full scientific reproducibility:

*   **`/notebooks/`**: Interactive analysis environments (Data Cleaning, Correlation, Moderation, and Robustness).
*   **`/scripts/`**: Automated Python pipelines for data processing and diagnostic testing.
*   **`/data/`**: Processed datasets (including `cleaned_dataset_alv.csv`).
*   **`/results/`**: Final statistical tables and high-resolution empirical figures.
